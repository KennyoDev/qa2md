# QA2MD

### Is a simple way to create a learning markdown file from a questions and answers CSV


## Requirements:

- Python installed


## Usage:

The usage is quite self-explanatory; you just enter the full path to the data (.csv) file and to the markdown file.


***Info: the data will be appended to the end of the file; plan accordingly.***


To see the results, you can check out the Examples folder with a .csv file and the markdown file after the script was run.
